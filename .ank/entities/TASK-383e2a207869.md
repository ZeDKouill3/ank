Independent of the ratification-by-ref decision and worth having before it:
four of the last five pull requests touched nothing outside .ank/, and each
paid 13 minutes for a matrix a corpus change cannot affect (757 s of it the
Windows suite). The ubuntu leg stays whole because fourteen test files read
the live repository through CARGO_MANIFEST_DIR/../.. (spec_page.rs, guide.rs,
skill.rs, reference_pages.rs among them) and a corpus diff can break them.

GitHub treats a job skipped by a job-level `if:` as a successful required
check; a workflow-level `paths:` filter leaves the check pending and blocks
the merge. Use the former, and say so in the comment.
